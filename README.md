# B2B Go-To-Market (GTM) Analytics & Decision-Maker Penetration Dashboard

## Overview
An end-to-end B2B sales performance and decision-maker reach analytics dashboard built using **PostgreSQL**, **DAX**, and **Power BI**. 

## Key Features & DAX Metrics
- **Executive KPI Scorecards**: Total Leads, Revenue Pipeline, Cost Per Lead (CPL), and Avg Conversion Rate.
- **Campaign Yield Analysis**: Multi-axis clustered column & line chart evaluating channel efficiency.
- **Decision-Maker Penetration Matrix**: Account coverage analysis across target industries highlighting decision-maker engagement rates.

## Architecture & Data Flow
`PostgreSQL Database` $\rightarrow$ `SQL Analytical Views` $\rightarrow$ `Power BI Data Model` $\rightarrow$ `DAX Measures` $\rightarrow$ `Executive Visual Dashboard`
